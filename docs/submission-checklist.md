# Submission checklist

From the 2026 Project Submission Guide and the 2026 Judging and Awards Guide (published Nov 13, 2026).
Deadline: click "Submit for Judging" before Sun Nov 15, 11:59 pm, local time of our Local Event.

## Eligibility

- [ ] Matt and Austin are confirmed (not waitlisted) at the same Local Event and appear on the team's Members tab.
- [ ] The project answers the "Planet X and SPHEREx" challenge.
- [ ] The project uses at least one NASA data source or resource (SPHEREx from IRSA).

## Project page fields

- [ ] Project name.
- [ ] High-level summary: what we built, how it addresses the challenge, why it matters.
- [ ] Demo link (public, no login).
- [ ] Final project link (public, no login): the live site and this repo.
- [ ] Project details: what it does, how it works, benefits, goals, tools, languages, hardware, software.
- [ ] NASA data and resources used.
- [ ] Space Agency Partner and other data used.
- [ ] References: every external resource, including open-source code, text, and images. Copy from `docs/references.md`.
- [ ] SI question: how SI tools were used. Judges don't see this answer, but they do see SI labels inside the project.
- [ ] Images can be uploaded straight to the page (JPG, PNG, GIF up to 10 MB). Videos and documents must be links.

## Demo

- [ ] A video of 30 seconds or less, or at most 7 slides including the title and intro slides. Over the limit means no Global Judging.
- [ ] English, or English subtitles if the video is in another language. Slides must be in English.
- [ ] Hosted on YouTube, Google Drive, GitHub, OneDrive, or Dropbox with a public link. Test it in a private window.
- [ ] Suggested video timing: 0:00 names and team, 0:02 the challenge, 0:05 title and tagline, 0:10 how it works plus the NASA and partner data, 0:20 to 0:30 the future.
- [ ] Slides show the team name, member names, the challenge, an image of the project, the user experience, and how NASA and partner data make it possible.
- [ ] SI-generated images or video carry a visible watermark. No NASA branding in SI-generated content.

## Final checks

- [ ] The live site loads from outside our network.
- [ ] Request a FortiGuard Web Filter Classification for any new domain so judges' networks don't block it (optional): https://www.fortiguard.com/faq/wfratingsubmit
- [ ] No images, video, or audio of anyone under 18.
- [ ] No NASA insignia or logos. No implied endorsement.
- [ ] OSI license present (Apache-2.0).
- [ ] Tick both boxes: the Terms and Conditions, and "Confirm All Work is Original" (all external resources listed in References).
- [ ] Submit. Resubmitting is allowed until the deadline, and only the last saved version is judged.
- [ ] The site stays online through Jan 26, 2027.
- [ ] Download participant certificates from each Profile after submitting.
